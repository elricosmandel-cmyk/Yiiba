# Yiib-Ya — Site Web

## Description
Site web officiel de **Yiib-Ya**, service de mise en relation pour les besoins à domicile à Ouagadougou, Burkina Faso.

---

## Contenu du site

Le site est un fichier unique : **yiibya.html**

Il contient les sections suivantes :
- **Hero** — Accroche principale et présentation du service
- **Barre de statistiques** — Chiffres clés (7 catégories, intervention en 1h, 7j/7)
- **Notre promesse** — Explication du modèle centralisé (le client commande, Yiib-Ya gère)
- **Comment ça marche** — 3 étapes simples
- **Nos services** — 7 catégories détaillées
- **Pourquoi Yiib-Ya** — Les 4 avantages clés
- **Notre équipe** — Esther et Béatrice avec leurs contacts directs
- **Témoignages** — 3 avis clients
- **Formulaire de contact** — Pour commander un service
- **Footer** — Liens et copyright

## Comment mettre le site en ligne

### Option 1 — Netlify (gratuit, recommandé)
1. Aller sur [netlify.com](https://netlify.com)
2. Créer un compte gratuit
3. Glisser-déposer le fichier `yiibya.html` dans la zone de dépôt
4. Le site est en ligne en moins d'1 minute
5. Vous obtenez une URL du type : `yiibya.netlify.app`

### Option 2 — Domaine personnalisé (recommandé à terme)
1. Acheter le domaine `yiibya.bf` auprès d'un registraire burkinabè (ex : ARCE Burkina)
2. Héberger le site chez un hébergeur local ou sur Netlify
3. Connecter le domaine à l'hébergement
